# AFK-Journey · 日常挂机

> 个人自用存档，基于 [MaaFramework](https://github.com/MaaXYZ/MaaFramework) 把对应游戏的日常任务自动化。
> 任务逻辑都写在 `assets` 里，欢迎直接 copy 改造。

## 它能做什么

基于 `assets/interface.json` 配置，自动完成以下日常任务：

- **🎮 进入游戏**：启动游戏并进入游戏
- **🤝 领取并赠送友情点**：领取并回赠友情点
- **⚡ 领取快速挂机奖励**：领取挂机收益并使用一次快速挂机次数
- **🏟️ 每日竞技场一次**：完成一次竞技场挑战
- **🛒 商城购买一次**：购买公会商店-每日刷新中的全英雄招募和史诗招募物品
- **📧 领取邮箱奖励**：领取邮箱内所有奖励

> 在 MaaFramework 启动器的任务列表中勾选 / 取消对应项，即可自定义要运行的任务。

## 使用前的游戏设置

- 模拟器分辨率建议 **1920 × 1080**
- 不自动领取日常奖励：次日会发到邮箱，由邮箱领取任务统一处理
